# Eng_SW_Project

Projeto acadêmico em equipe (UNIFESP, Engenharia de Software). O professor avalia todos os commits.

- Siga o [CONTRIBUTING.md](CONTRIBUTING.md): nada de commit direto na `main`, branches `tipo/descricao`, commits em Conventional Commits (português, imperativo), PRs pequenos.
- Só faça commit ou push quando o usuário pedir. Um commit por mudança lógica.
- Nomes de código em inglês; textos para o usuário e documentação em português.
- Mudou o `schema.prisma`? Gere e commite a migração junto; nunca edite migração já mergeada.
- Não versione `.env` nem PDFs de `docs/referencia/`.
